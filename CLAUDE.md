# Opcare DAQ — notes for Claude sessions

Opcare Smart Services' Data Acquisition Platform (closed source). Owner: Khaled (CEO).

- Layout and architecture: README.md, platform/README.md, connectors/modbus/README.md.
- Connector rules: docs/connector-spec/CONNECTOR_SPEC.md is normative. Schemas are generated by
  docs/connector-spec/tools/gen_schemas.py — edit the generator, never the JSON.
- Read-only: connectors never write to field devices (spec section 12). New request types need a spec change.
- Licences: no AGPL, BSL or non-commercial dependencies in this repository; GPL code (e.g. lib60870)
  only in a separate repository that talks over MQTT.
- Tests: `python -m pytest connectors platform edge -q`. CI (.github/workflows/ci.yml) adds a real Mosquitto
  broker, PostgreSQL + TimescaleDB, Windows/macOS launcher self-tests and Docker builds. Keep CI green.
- Work on a branch and open a pull request for Khaled to review; do not push to main directly.
